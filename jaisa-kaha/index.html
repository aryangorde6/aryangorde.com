Agents with owners · Flip the Switch, Track 02

जैसा कहाJaisa Kaha

“as she said it”

An AI scribe that refuses to make up a cook's quantities. It writes down only the amounts that were said and keeps a gap where none was (or where the cook said “by feel”), and only the cook's own account can fill it. On a test sentence, four models out of four turned “ghee, by feel” into a number.

Demo video ↗ Source ↗

  • 7/8missing amounts four models turned into numbers on a plain prompt, on the demo dish.
  • 0numbers on Pothi's page that aren't a quote from the tape or typed by the cook.
  • 87tests, Python standard library only.

It never types a quantity

Lekhak (“writer”), an LLM on Amazon Bedrock in Mumbai, writes the draft as JSON, and every amount is a range of words on the tape. Pothi (“the book”) is plain code with no model: it reads the cited words off the tape and marks each line said, a gap for the cook, or struck.

Switch writes the refusal

Pothi belongs to the cook in Switch's records. When I or the AI try to give it a number, Switch's server refuses under Pothi's name, and Pothi's code never receives the message.

Measured before the first recording

Both prompts were committed with their SHA-256 before the first real recording, then run on four models on Bedrock. On the demo dish the plain prompt made up 7 of 8 missing amounts. One recipe is a tiny sample, and the README says so.

For Mom's recipes

Built for my mother's recipes; the page is for my sister, who is learning them. In the demo I play the cook on a second account, and the voice note is a synthetic voice. Both are labelled on screen.
